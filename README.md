Sistema de Gestión de Canchas de Fútbol
Descripción
Sistema de escritorio desarrollado para administrar un complejo deportivo y gestionar el alquiler de canchas de fútbol.
El proyecto permite organizar las reservas, controlar la disponibilidad de las canchas y administrar la facturación.
Funcionalidades principales
Gestión de clientes.
Administración de canchas.
Registro y modificación de reservas.
Consulta de disponibilidad horaria.
Cálculo automático de tarifas.
Diferenciación de precios diurnos, nocturnos y de fines de semana.
Gestión de facturas.
Control de reservas pendientes de facturación.

Tecnologías utilizadas
Visual Basic .NET
Windows Forms
MySQL
Visual Studio

Objetivo del proyecto
Desarrollar una aplicación que facilite la administración de un complejo deportivo, centralizando la información de clientes, canchas, reservas y facturas.

Estado

Proyecto funcional en etapa de documentación y presentación
